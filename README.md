# Практическая работа по MongoDB — вариант 7 «Склад»

В заголовке методички указана практика № 9, а в инструкциях по запуску и сдаче указан номер 7. В работе использованы предусмотренные методичкой имя базы `lab7_variant7` и шаблон имени отчёта `Отчет_ФИО_ПР7.docx`.

## Запуск

Нужны Node.js 22.12 или новее и локальный сервер MongoDB. Для демонстрации используйте Compass и Postman.

В корне проекта выполните:

```powershell
npm ci
npm run seed
npm run api
```

В отдельном терминале запустите Vue:

```powershell
npm run dev
```

Откройте [Vue](http://localhost:5173). API доступен на [порту 3001](http://localhost:3001/api/items). Если MongoDB работает по другому адресу, задайте `MONGODB_URI` перед запуском `seed` и `api`. В Compass укажите тот же URI. При изменении порта API задайте `PORT` для API и `API_TARGET` для Vite.

## MongoDB

`npm run seed` добавляет три поставщика и четыре складские позиции. Повторный запуск сохраняет существующие документы и добавляет отсутствующие демонстрационные записи.

- `suppliers` хранит строковый `_id`, название и город поставщика.
- `stock` хранит название, остаток `quantity`, ссылку `supplierId`, вложенный объект `location` и массив операций `history` с BSON-датами.
- Индексы `name_1`, `quantity_-1`, `supplierId_1_quantity_-1` и `history.action_1` созданы сверх стандартного индекса `_id_`.

Запустите команды поиска, проверки индекса, сортировки, проекции и агрегации:

```powershell
mongosh "mongodb://127.0.0.1:27017/lab7_variant7" --file backend-lab7/demo.mongosh.js
```

Встроенная оболочка Compass также поддерживает команды из `backend-lab7/demo.mongosh.js`. Для демонстрации списка индексов отдельно выполните `db.getSiblingDB('lab7_variant7').stock.getIndexes()`.

Исходная статистика по поставщикам, отсортированная по среднему остатку:

| Поставщик | Средний остаток | Всего единиц | Позиций |
| --- | ---: | ---: | ---: |
| ПакЛайн | 240 | 240 | 1 |
| МетизСервис | 80 | 80 | 1 |
| ТехСнаб | 80 | 160 | 2 |

## API и Postman

Импортируйте `Склад.postman_collection.json`. Папка «Чтение» содержит GET-запросы и проверки ответов. Запрос из папки «Запись» добавляет позицию, после чего меняются общий список и статистика.

| Запрос | Назначение |
| --- | --- |
| GET /api/items | Остатки со всеми полями |
| GET /api/items?minQuantity=100 | Остаток от 100 единиц включительно |
| GET /api/items?supplier=tekhsnab | Позиции поставщика ТехСнаб |
| GET /api/items?action=issue | Позиции с выдачей в истории |
| GET /api/items?search=кабель | Поиск подстроки без учёта регистра |
| GET /api/items?sort=quantity_desc&limit=2 | Два наибольших остатка |
| GET /api/items/stats | Средний и суммарный остаток и число позиций по поставщикам |
| GET /api/suppliers | Список поставщиков для Vue |
| POST /api/items | Добавление позиции с адресом ячейки и историей |

В Vue можно совместить фильтры. Например, выберите поставщика «ТехСнаб», операцию «Выдача» и минимальный остаток 100, затем нажмите «Найти». На исходных данных останется «Кабель USB-C». Статистика охватывает всю базу.
